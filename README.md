História do Jogo

Batman está patrulhando as ruas de Gotham quando ele avista no céu o batsinal, ao chegar conversa com o comissario Gordon, que lhe fala que o Coringa fugiu do azilo arkham e está atirando cartas envenenadas com o seu gás do riso. O objetivo do jogador é desviar dos ataques pelo maior tempo possível, acumulando pontos e tentando bater o recorde de pontuação. Assim salvando Gotham mais uma vez das palahaçadas do Coringa>
